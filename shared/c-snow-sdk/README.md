# What does c-snow-sdk mean?

Like dsemm, here are a few ideas. Pick the one you like the most:
- c-snow is the Cross-platform System for Native Operation Wrapping. It's sort of like AMD's Heterogeneous-computing Interface for Portability, it's a statement on computing more than anything.
- It's an sdk to access weather data from C.
- The word *Nitro* came from *Nitre*, which refers to the naturally occurring mineral form of Potassium Nitrate. And before being known as *Nitre*, it was known as *Saltpetre*. And before even *that*, it was known as Chinese Snow. Naturally occurring deposits of this stuff usually form a powdery white layer on soil, cave walls, and other damp surfaces. Because it looked like fresh snow, when it got traded, it eventually became referred to as Chinese Snow by Arab and Persian traders carrying it from China to be used elsewhere.
